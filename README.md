## How to run

```bash
# Create and activate the virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install exact pinned dependencies
pip install -r requirements.txt

# Regenerate dataset (spec-exact, seed=21)
python3 generate_data.py

# Run the verification suite (72 checks)
python3 test_pipeline.py

# Open the notebook
jupyter notebook ml_pipeline.ipynb
```

The notebook survives **Restart Kernel & Run All** with zero error cells.

## Limitations (honest)

- Correlation ≠ causation — studying more may not *cause* higher scores
- Synthetic data — real students might have different patterns
- Only 5 features — many real factors omitted
- Single train/test split — cross-validation would be more robust
- No hyperparameter tuning — random forest used default settings
- Threshold sensitivity — different distinction thresholds change class balance
